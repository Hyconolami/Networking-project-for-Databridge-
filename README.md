## 📘 Project Overview  
This project focuses on enhancing **network security** within a multi-department organization by implementing **Access Control Lists (ACLs)** on a Cisco router.  
The goal was to manage and restrict access between **Admin**, **Sales**, and **HR** departments, ensuring that only authorized devices could reach the **Admin Server (HTTP)**.  

By applying ACLs, unauthorized communication was blocked, demonstrating how access control policies can protect sensitive resources and maintain network integrity.
